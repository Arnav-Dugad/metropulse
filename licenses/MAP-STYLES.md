# Map styles

The bundled map styles (`core/map/src/main/assets/map/pulse-light.json` and `pulse-dark.json`) are
generated by `tools/map_styles.py` from OpenFreeMap's Positron style. MetroPulse changes the
colours, uses English labels, removes road shields and adds 3D buildings.
